# 失败升级与人工接管

子代理失败路径（顺序固定）：

1. **retry ×1**：同 spec 重试一次。
2. **degrade**：该证据面标「未取证」，主代理知情继续，不假装有证据。
3. **escalate-lead**：主代理决定换 provider / 改假设。
4. **用户**：超预算或全组失败 → 「调查受阻」条，给出扩大预算 / 换路径 /
   人工接管选项。

特殊规则：

- 子代理超时（maxWallMs）按失败处理，走同一路径。
- Executor 失败：**立即停止后续 step、保留现场**；命中回滚触发条件 →
  产出**新的**回滚审批简报，绝不自动回滚。
- 调查中发现疑似入侵：停止常规处置、保全证据，转 `pb.security-triage`。
- Escalated 出口只有 Closed：人工接管后归档，Agent 不再自行操作。
